# 🔗 URL Shortener App

A modern, fast, and full-stack URL Shortener web application built using **Node.js, Express, MongoDB, and EJS** with a sleek **Glassmorphism UI**.

## ✨ Features
- 🚀 Shorten long URLs into clean, unique short links.
- 🎨 Modern Glassmorphism UI design.
- 💾 Persistent storage using MongoDB Atlas.
- ⚡ Fast redirection to original URLs.

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose)
- **Frontend:** EJS, CSS3 (Glassmorphism design)
- **Environment Management:** Dotenv

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/ArpitKumarGoel/URL-Shortener-Nodejs.git](https://github.com/ArpitKumarGoel/URL-Shortener-Nodejs.git)
   cd URL-Shortener-Nodejs
   ```
2. **Install dependencies:**
   ``` bash
   npm install
   ```
3. **Set up Environment Variables:**
   Create a .env file in the root folder and add:
   ```bash
   MONGO_URI=your_mongodb_connection_string
   ```
PORT=1000

4. **Start the server:**
```bash
npm start
# or for development:
nodemon server.js
```
5. **Open http://localhost:1000 in your browser.**
